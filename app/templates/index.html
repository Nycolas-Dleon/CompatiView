Sobre

Montar um PC pode ser um quebra-cabeça caro.

O CompatiView chega para simplificar essa tarefa, funcionando como um guia inteligente que verifica em tempo real se as peças escolhidas funcionam bem juntas. Com uma interface intuitiva, ele não apenas diz "sim" ou "não" para a sua escolhas, mas também sugere componentes substitutos que se encaixam perfeitamente no seu setup.

O CompatiView é a ferramenta definitiva para entusiastas de tecnologia, gamers e profissionais que buscam montar o PC dos sonhos sem dores de cabeça. Com ele, você pode explorar as possibilidades, comparar componentes e garantir que cada peça escolhida seja a melhor para o seu projeto.

É a segurança de que cada centavo investido no seu hardware terá o desempenho esperado, sem surpresas na hora da montagem.

Este é um projeto acadêmico desenvolvido por um grupo de estudantes do curso de Engenharia de Software do Instituto Federal da Paraíba (IFPB) - Campus João Pessoa. O objetivo é criar uma aplicação web que auxilie os usuários a verificar a compatibilidade entre diferentes componentes de hardware para montagem de computadores, proporcionando uma experiência mais segura e informada na escolha dos componentes.

O projeto é uma iniciativa para aplicar os conhecimentos adquiridos durante o curso, utilizando tecnologias modernas de desenvolvimento web, como Flask para o backend e HTML/CSS para o frontend. A aplicação visa oferecer uma interface amigável e intuitiva, permitindo que os usuários possam facilmente verificar a compatibilidade entre processadores, placas-mãe, memórias RAM, placas de vídeo e outros componentes essenciais para a montagem de um computador.
